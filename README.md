## Documentation Standards

All build documentation follows these conventions:

### File Structure
- **H1**: Build name and class
- **H2**: Major sections (TALENTS, WEAPONS, CURIOS)
- **H3**: Subsections and tier levels
- **Tables**: Perk/blessing selections with values
- **Bold**: Talent names, blessings, key terms
- **Em-dashes (---)**: Section separators

### Each Build Includes
- Talent tree breakdown (all 6 tiers)
- Weapon recommendations with blessings
- Curio optimization (blessings + perks)
- Playstyle notes and strategy
- Difficulty and skill rating

### Each Class README Includes
- Build index table
- Class-specific mechanics guide
- "Choose Your Build" decision guide
- Universal survival tips
- Weapon tier lists (S/A/B/C rankings)
- Curio blessing/perk priorities
- Progression path (Level 1-30+)
- Team composition synergy
- FAQ section

## Build Philosophy

These builds are designed with the following principles:

### Auric-First Optimization
- All builds target Auric (highest) difficulty
- Maximum survivability focus
- Elite and special threat priority
- Team synergy considerations

### Practical Usability
- Work with adequate gear, excel with perfect gear
- Clear explanations of "why" for each choice
- Multiple playstyle options per class
- Adaptability to team composition

### Community-Tested
- Based on GamesLantern data
- Validated by Auric gameplay
- Updated for current meta
- Feedback-driven iterations
