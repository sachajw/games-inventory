## VENTING SHRIEK MECHANICS

### What Venting Shriek Does

| Effect | Details |
|--------|---------|
| **Primary** | Quells 50% peril instantly |
| **Secondary** | AoE stun around you |
| **Radius** | ~10 meters |
| **Stun Duration** | ~2-3 seconds on most enemies |
| **Damage** | Light damage to all affected |
| **Special Interaction** | Doesn't stun Mutants or Bosses |

### The Perpetual Stun Lock Cycle

**With This Build:**
1. **Base cooldown** - ~45 seconds
2. **Quicken talent** - -25% = ~34 seconds
3. **Seer's Presence** - -15% = ~29 seconds
4. **Combat Ability Regeneration** - -12% = ~24 seconds

**Result:** Venting Shriek every ~24 seconds

### Think Fast Synergy

**How It Works:**
- Using Venting Shriek quells 10% peril
- Combined with 50% quell from Shriek itself
- Net result: ~60% peril removed instantly

**Why This Matters:**
- Can cast more Brain Bursts between Shrieks
- Less time spent quelling manually
- More offensive pressure
- Safer peril management

## COMBO ROTATIONS

### The "Perpetual CC" Cycle
1. **Group of enemies approaches**
2. **Venting Shriek** - Stuns everything + removes peril
3. **Greatsword cleave** - While they're stunned
4. **Soulblaze applied** - Via Blazing Spirit
5. **Ascending Blaze procs** - Restores warp charges
6. **Repeat** - When Shriek is ready again

### The "Elite Wave" Response
1. **Multiple elites spawn**
2. **Venting Shriek immediately** - Stuns all non-Mutants
3. **Focus Mutants first** - They don't get stunned
4. **Greatsword special** - Infinite cleave through stunned elites
5. **Shriek again** - When cooldown finishes (~24 seconds)

### The "Peril Dump"
1. **High peril from casting** - 75%+
2. **Venting Shriek** - Drops to ~15%
3. **Think Fast bonus** - Additional 10% quell
4. **Back to safe** - Can cast again
5. **Cycle continues** - Perpetual peril management

### The "Revive Protection"
1. **Teammate downed in bad spot**
2. **Venting Shriek** - Stuns all nearby enemies
3. **Safe revive window** - ~2-3 seconds
4. **Complete revive** - Teammate up safely
5. **Deflector block** - If needed during revive

## PLAYSTYLE GUIDE

### Core Philosophy
> "I don't kill enemies one by one - I stun them all, then clean up. My shriek is the rhythm of battle."

### Positioning
- **Center of action** - Shriek radius affects everything
- **Near teammates** - Protection for revives
- **Choke points** - Maximize Shriek coverage
- **Flank position** - Catch enemies from angles

### Shriek Usage Guidelines

| Situation | Shriek? | Why |
|-----------|---------|-----|
| **Peril at 75%+** | YES | Peril dump + stun |
| **Horde incoming** | YES | Stuns entire horde |
| **Elite wave** | YES | Stuns most elites |
| **Teammate down** | YES | Creates revive window |
| **Surrounded** | YES | Escape + stun |
| **Single elite** | NO | Waste of cooldown |
| **Boss fight** | SITUATIONAL | Doesn't stun boss |
| **Peril low** | NO | Save for when needed |

### Between Shrieks
1. **Greatsword cleave** - Primary damage
2. **Inferno secondary** - Soulblaze stacking
3. **Brain Burst** - With Think Fast quell
4. **Deflector block** - When taking ranged fire
5. **Manage peril** - Don't reach critical levels
